# 红果家庭版 iOS 测试介绍

仅用于 TestFlight 测试。以下介绍已通过 106 的 App Store Connect API 填写并读回核对；App Store 页面仍为未提交草稿，未关联上架构建。

副标题：深色追剧界面，本机记录随时续看

红果家庭版是一个个人开发的非官方短剧播放项目，目前通过 TestFlight 邀请体验。

【推荐】浏览真人短剧、漫剧和 AI 剧目录，通过分类与搜索找到感兴趣的作品。
【剧场】查看作品详情与选集，播放来源已公开开放的剧集。来源未开放的剧集会标记为锁定，不能播放；本应用不提供解锁功能。
【追剧】收藏喜欢的作品，方便再次打开。
【我的】查看本机观看历史、继续观看和管理本地记录。收藏、历史与续播进度保存在当前设备，不会自动跨设备同步；无需注册或登录账号。

播放页面采用深色界面，支持暂停、进度拖动、选集及手机横竖屏适配。底部选集面板突出显示当前播放的一集。

作品目录、图片和视频来自应用接入的公开来源，内容权利归相应权利人所有。本项目并非内容平台官方客户端，与相关平台无隶属或合作关系，也不代表来源平台。内容和播放可用性取决于来源及网络，部分作品或集数可能无法播放。

本轮测试请重点反馈：目录和搜索、公开剧集播放、返回目录、当前集标记、横竖屏适配，以及本机收藏、历史与续播的使用体验。请勿在反馈中提供账号密码或其他敏感信息。

测试重点：请重点测试推荐、剧场、追剧、我的四个页面；目录与搜索；公开剧集播放、暂停、拖动进度及返回目录；深色底部选集、当前播放集高亮与锁定集提示；手机横竖屏；本机收藏、观看历史和续播。无需登录，无云同步。

支持页面：https://nas.zhangyue.site/hongguo-ota/ios/
