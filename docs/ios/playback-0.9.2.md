# 0.9.2 播放回归

本次修复：安卓 Flutter 发布包启动时，JNI 动态引用的 Kotlin 协程和 Result 类型被 R8 删除或重命名；补齐精确的保留规则。搜索支持真人短剧和漫剧，结果保留来源分类；数字年份搜索无有效结果时，仅补查一次中文写法。

验证：

- Android API 28 ARM64 专用模拟器：GitHub 云端 0.9.2(5) 发布包实际启动、第一集播放、切第二集、29秒时强制关闭；重开应用后第二集记录保留，进入后从原进度继续，截屏到34秒。未出现原来的 JNI 启动异常。
- iOS 26.5 专用模拟器：《王妈》播放、暂停、切第二集；持久化8秒以上进度，销毁应用并重新创建后续播通过。
- iOS 26.5 专用模拟器：搜索“重生85”，找到《重生八五，靠购物返现系统赢麻了》100集；实际播放、暂停、当前集选集、切第二集、持久化进度并重新创建应用后续播通过。
- 自动化测试覆盖取消加载、选集、历史持久化、公开接口契约、清晰度回退和跨分类搜索。

边界：以上为模拟设备，未连接用户实体手机或投影。本次没有接入受保护媒体的离线解密。当前公开源仍限制部分集数，该剧实际为360p，不能视为高清验收通过。

分发边界：Flutter Android 使用独立预览包名，不能用它替换现有原生手机/投影的正式OTA。原生正式渠道另行保持原包名与签名升级；不能拿Flutter预览包覆盖它。iOS 0.9.2(6) 已经106 API上传，Apple处理完成，内部状态IN_BETA_TESTING，未开启外部邀请。此版本仅为启动/搜索/续播修复，不是全集高清版。
